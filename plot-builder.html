    Guide

    How to build a figure

    Combine columns from one or more CSV files in one figure, style it while the preview redraws, then download a PNG or SVG, or a matplotlib script that draws the same figure.

    1

    Add data

    Drop one or more CSV, TSV or text files with a header row, or click Load example. Rows where a chosen column is not a number are left out of that trace.

    2

    Set the traces

    A trace plots one column against another, from any loaded file. The first is drawn as soon as a file loads. Add more to overlay them, and give each a legend name, colour, line style and marker.

    3

    Style it

    Label the axes, choose the figure size, set limits, log scales, frame, ticks, grid and legend, then the font and the text and line sizes. Every change redraws the preview.

    4

    Export or reproduce

    Download PNG or Download SVG at the size you set, or open Python script for a matplotlib script that draws the same figure from your CSV.

    Sizes

    What you see is the size you get

    The figure has a physical size, set the way journals set it: width and height in inches, centimetres or millimetres, a resolution in dpi, and text and lines in points (1 pt = 1/72 in).

    The preview

    The preview draws the figure at its export size and scales the whole of it to fit the screen, so text, lines, margins and the legend keep the proportions they will have on paper. The line above it says how much it is enlarged: an 8 pt label looks larger at 230% than it will print.

    PNG

    Width times resolution gives the pixels: 3.5 in at 300 dpi is 1050 px. The resolution is written into the file, so Word, LaTeX and Illustrator place it at 3.5 in rather than guessing. Sizes in pixels are converted at the chosen resolution: 1200 px at 300 dpi is a 4 in figure.

    SVG

    The SVG is sized in points (3.5 in is 252 pt), and its text stays text, so it can be edited and scaled without loss. The fonts on offer are the ones installed almost everywhere, so the file looks the same when it is opened elsewhere.

    The Python script

    The matplotlib script uses the same figure size and dpi, point sizes, colours, axis limits, scales, ticks and legend, and puts the plot area where the browser put it. It saves at exactly the size you set: it does not use bbox_inches='tight', which would crop the figure to a different size.

    Good practice

    Making a figure that reads well

    A few conventions that make scientific figures clearer and more honest.

    Label your axes with units

    An axis without units is ambiguous. Write the quantity and its unit, e.g. Time (s) or Concentration (mM). The label fields feed the preview, both downloads and the matplotlib script.

    Use log scales deliberately

    A log axis linearises exponential or power-law data and shows several orders of magnitude at once, but it can flatter noisy data. Use it when the process is multiplicative, and say so in the caption. Points at or below zero cannot be drawn on a log axis; the trace says how many were left out.

    Colours that survive greyscale and colour blindness

    Around 8% of men have some colour-vision deficiency, and many journals print in greyscale. The default colours are the Okabe–Ito palette recommended by Wong (2011), which stays distinct for the common forms of colour blindness. Give traces different line styles or markers as well, so colour is not the only difference.

    Reproducibility

    The Python script means a figure isn't a dead end: it regenerates the plot from the same CSV, and can carry the data inside it, so you can version-control it alongside your analysis. Everything runs in your browser; no data leaves your machine.
