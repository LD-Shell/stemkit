Data & Statistics

8 tools

Clean, test, fit and plot experimental data.

Plot Digitizer

Extract data points from a graph image by clicking or tracing curves, then export the numbers as CSV.

Data Cleaner

Clean, normalize and log-transform messy CSV datasets, then download the tidied file.

Statistics Calculator

Run t-tests, ANOVA with post-hoc comparisons, correlation and non-parametric tests, with effect sizes, plots and advice on which test fits.

Error Bar Generator

Compute mean, SD, SEM, median, IQR and confidence intervals per group, then plot and export error bars.

Outlier Detector

Flag anomalies with Z-scores, Tukey’s IQR fences or the robust modified Z-score.

Curve Fitter

Fit linear, polynomial, exponential, power or log models and read off coefficients, R² and RMSE.

Plot Builder

Overlay multiple datasets in one figure, style it fully, and export PNG/SVG or matplotlib code.

XVG Visualizer

Plot GROMACS .xvg and CSV logs interactively; select columns, smooth, and export the figure or Python code.

Computational Chemistry

4 tools

Inspect structures, prepare coordinates and write the batch scripts for a run.

Structure Inspector

Render PDB, CIF, GRO, XYZ and more in 3D; select atoms, measure geometry and export a figure.

Coordinate Manipulator

Translate, rotate and re-box PDB, GRO and XYZ coordinates, and convert between the formats.

Scientific Converter

Convert energy, length, pressure, dipole, polarizability, spectroscopic and temperature units against CODATA values.

MD Workflow Generator

Build batch scripts for GROMACS and LAMMPS on SLURM, PBS, LSF or Grid Engine, and write PLUMED inputs.

Writing & Citations

6 tools

Equations, tables and a bibliography that builds.

Equation Formatter

Build LaTeX equations and matrices visually with a live preview, then copy the code.

Visual LaTeX Tables

Paste a table from Excel, edit and merge cells visually, and copy clean LaTeX (booktabs) output.

DOI to BibTeX

Paste DOIs and get ready-to-use BibTeX entries resolved from Crossref.

BibTeX Deduplicator

Scan a .bib library and merge duplicate entries by DOI and title.

BibTeX Sanitizer

Fix messy BibTeX exports: standardize capitalization, repair braces and clean fields.

Journal Abbreviator

Convert full journal names to their ISO 4 / CASSI standard abbreviations.

Focus & Flow

3 tools

Not research tools: a timer, a decision matrix and a physics toy for the breaks in between.

Ambient Pomodoro

A focus timer with adjustable ambient sounds like rain and cafe noise for deep work.

Decision Matrix

Weigh options against criteria in a scored matrix to rank your best choice.

Kinetic Sandbox

An interactive fluid and particle physics playground, a calm visual break.

Numbers you can check

The calculations behind the tools are a separate library, @stemkit/core: 17 modules covered by 1,208 tests, which also runs in Node, so a figure made here can be regenerated from a script. Moving the code there and testing it against reference values turned up four errors that had already shipped:

  • Wavelength conversion returned a plausible but wrong number.
  • Skewness used the sample, not the population, standard deviation.
  • Virtual sites in water inflated the system mass by 67%.
  • The D’Agostino–Pearson test was fed the adjusted G1, a 21% error in K² at n = 10.

Each now has a regression test, and the changelog records every fix that changed an output.

What leaves your computer

Nothing you open. Files are read in the browser and never uploaded, there is no account, and a page keeps working offline once it has loaded.

Two features go online, and only when you use them: DOI to BibTeX looks up the DOIs you give it, and the structure inspector can fetch an entry from the PDB by its ID.
