Data & Statistics

8 tools

Clean, test, fit and plot experimental data.

Plot Digitizer

Data Cleaner

Statistics Calculator

Run t-tests, ANOVA with post-hoc comparisons, correlation and non-parametric tests, with effect sizes, plots and advice on which test fits.

Error Bar Generator

Compute mean, SD, SEM, median, IQR and confidence intervals per group, then plot and export error bars.

Outlier Detector

Flag anomalies with Z-scores, Tukey’s IQR fences or the robust modified Z-score.

Curve Fitter

Plot Builder

Overlay multiple datasets in one figure, style it fully, and export PNG/SVG or matplotlib code.

XVG Visualizer

Plot GROMACS .xvg and CSV logs interactively; select columns, smooth, and export the figure or Python code.

Use the library behind the tools

Every calculation on this site comes from @stemkit/core: 17 modules covered by 1,208 tests validated against SciPy, NumPy and statsmodels. The same functions run in Node, so an analysis explored here can be scripted, version-pinned and re-run.

  1. Clone the repository. It needs Node 18 or later and nothing else: no npm install.

    Terminal 
    git clone https://github.com/LD-Shell/stemkit.git
cd stemkit

  2. Save an example in the stemkit folder under the name shown, with any data file it reads beside it, and run it: node pick-test.mjs.

    Summarise every series in a GROMACS .xvg file, named by its legend.

    xvg-summary.mjs 
    import { readFileSync } from 'node:fs';
import { parseXvg, extractColumn, columnStats } from '@stemkit/core';

const { matrix, headers } = parseXvg(readFileSync('rmsd.xvg', 'utf8'));

headers.slice(1).forEach((name, i) => {
  const s = columnStats(extractColumn(matrix, i + 1));
  console.log(`${name}: ${s.mean.toFixed(3)} ± ${s.std.toFixed(3)}`);
});

    Let the assumption checks pick the test, then run it.

    pick-test.mjs 
    import { createRequire } from 'node:module';
import {
  registerVendor, recommendTest, independentTTest, mannWhitneyU
} from '@stemkit/core';

const require = createRequire(import.meta.url);
registerVendor({ jStat: require('./js/dependencies/jstat.min.js') });

const control = [4.1, 4.3, 3.9, 4.4, 4.0, 4.2, 4.5, 3.8, 4.1, 4.6];
const treated = [5.0, 5.2, 4.8, 9.9, 5.1, 4.9, 5.3, 5.0, 12.4, 5.2];

const advice = recommendTest({
  design: 'independent', groups: [control, treated]
});
console.log(advice.reason);

const r = advice.test === 'mann-whitney'
  ? mannWhitneyU(control, treated)
  : independentTTest(control, treated);
console.log(`${advice.test}: p = ${r.p.toPrecision(3)}`);

// Group 2 departs from normality (D'Agostino p = .005), so a
// rank-based test is safer.
// mann-whitney: p = 0.000154

    Mass and radius of gyration of a .gro structure, with the unit made explicit.

    gyration.mjs 
    import { readFileSync } from 'node:fs';
import {
  parseStructure, centreOfMass, radiusOfGyration, convert
} from '@stemkit/core';

const gro = readFileSync('protein.gro', 'utf8');
const { atoms, unit } = parseStructure(gro, 'gro');
const { mass } = centreOfMass(atoms);
const rg = convert(radiusOfGyration(atoms), 'length', unit, 'angstrom');

console.log(`${atoms.length} atoms, ${mass.toFixed(1)} Da`);
console.log(`Rg = ${rg.toFixed(2)} Å`);

    Convert between units on CODATA values.

    units.mjs 
    import { convert, convertTemperature } from '@stemkit/core';

// 1 hartree in kcal/mol, 1 eV in kJ/mol, 298.15 K in °C
console.log(convert(1, 'energy', 'hartree', 'kcal'));  // 627.5094740631
console.log(convert(1, 'energy', 'ev', 'kj'));         // 96.48533212331287
console.log(convertTemperature(298.15, 'k', 'c'));     // 25

    A SLURM array job for GROMACS, with a warning about memory in flight.

    array-job.mjs 
    import { generateScript } from '@stemkit/core';

const { script, warnings } = generateScript({
  engine: 'gromacs', jobName: 'replicas', modules: ['gromacs/2023.3'],
  nodes: 1, gpus: 1, cpusPerTask: 16, memory: '32G', walltime: '24:00:00',
  array: true, arrayRange: '1-100%10', tpr: 'md.tpr', deffnm: 'md'
});

console.log(script);
warnings.forEach(w => console.warn(`[${w.level}] ${w.message}`));

// [warn] Array job: --mem=32G is per task. With 10 task(s) running
// concurrently that is 320G in flight. ...

    Merge duplicate entries in a .bib library, keeping the most complete.

    dedupe-bib.mjs 
    import { readFileSync, writeFileSync } from 'node:fs';
import { createRequire } from 'node:module';
import {
  registerVendor, parseBibtex, deduplicateAuto, serialiseLibrary
} from '@stemkit/core';

const require = createRequire(import.meta.url);
registerVendor({
  bibtexParse: require('./js/dependencies/bibtexParse.min.js')
});

const { entries } = parseBibtex(readFileSync('refs.bib', 'utf8'));
const { entries: kept, removed } = deduplicateAuto(entries);

writeFileSync('refs.clean.bib', serialiseLibrary(kept));
console.log(`${removed} duplicate(s) removed, ${kept.length} kept`);

Every function is documented in the library reference.

What leaves your computer

Nothing you open. Files are read in the browser and never uploaded, there is no account, and a page keeps working offline once it has loaded.

Two features go online, and only when you use them: DOI to BibTeX looks up the DOIs you give it, and the structure inspector can fetch an entry from the PDB by its ID.
