Guide

How to visualize your data

Drop a GROMACS .xvg (or any whitespace/CSV numeric table) and explore every column interactively, the parser reads the embedded metadata so your axes and legends come out labelled.

1

Load a file

Drag & drop or select a .xvg, .csv, .txt or .dat file, or press Load a sample to try a synthetic RMSD and radius-of-gyration trace. Everything is parsed in your browser.

2

Pick columns

Choose which column is the X axis, then tick any number of series to overlay; a series on a very different scale can go on a second y-axis on the right. Legends and axis titles are pulled from the file's @ metadata when present.

3

Adjust the view

Under Appearance, switch to a log y-axis, show markers, or apply spline smoothing. The plot zooms and pans from the toolbar that appears over its top-right corner.

4

Export or reproduce

Press Download PNG to save the plot, or Python code to copy matplotlib code that redraws the current selection from your file with numpy.loadtxt.

Format

About the GROMACS .xvg format

.xvg is the plain-text output written by GROMACS analysis tools (and read by Grace/xmgrace). Knowing its structure explains what this tool does automatically.

Comment & metadata lines

Lines starting with # are comments; lines starting with @ are Grace formatting commands. This tool reads @ title, @ xaxis label, @ yaxis label and @ sN legend to label the plot, and skips everything else, so the raw numeric matrix is all that gets plotted.

The data block

Below the metadata is a whitespace-separated numeric table: the first column is usually the independent variable (time, distance, reaction coordinate) and each remaining column a data series. Common outputs include RMSD (gmx rms), radius of gyration (gmx gyrate), and PMF/free-energy profiles.

Reproducing in Python

The Python code export uses numpy.loadtxt(..., comments=['@', '#']), which is the idiomatic way to read an .xvg: the comments argument makes NumPy skip exactly the metadata lines described above, leaving the numeric matrix. The generated script plots only the columns you selected, with a second y-axis (ax.twinx()) for any series you put on the right.
